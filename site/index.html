scafctl Flagship CLI · v0.47.0

macOSLinuxWindowsx86_64 & ARM64

A configuration discovery and scaffolding tool using CEL for dynamic evaluation

brew install oakwood-commons/tap/scafctl
Or download Apple Silicon / Intel binaries from GitHub Releases.
curl -fsSL https://github.com/oakwood-commons/scafctl/releases/download/v0.47.0/scafctl_0.47.0_Linux_x86_64.tar.gz | sudo tar -xz -C /usr/local/bin scafctl
Also via Homebrew (brew install oakwood-commons/tap/scafctl) or Linux_arm64 on Releases.
curl.exe -fsSLO https://github.com/oakwood-commons/scafctl/releases/download/v0.47.0/scafctl_0.47.0_Windows_x86_64.zip; tar.exe -xf scafctl_0.47.0_Windows_x86_64.zip scafctl.exe
Windows_arm64.zip also available on GitHub Releases.
